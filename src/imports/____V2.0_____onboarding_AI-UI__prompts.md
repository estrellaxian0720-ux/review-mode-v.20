> 用途：直接喂给 v0 / Lovable / Figma AI / Claude 等 UI 生成工具，产出新用户价值介绍流程的每一屏。
> 产品：云记 · 备考学习 App，**平板端，中文界面，需横竖两套布局**。

## 通用设计令牌（每段 prompt 开头都粘贴，与主 prompts 文档一致）

```
品牌定位：云记 · 备考学习 App，平板端，中文界面。
场景：新用户首次进入学习模式的 onboarding 体验流，用预制示例内容跑通一遍完整创建流程、外化产品价值，最终引导到订阅支付。
气质：克制、专业、有呼吸感；不花哨；以阅读和专注为先。庆祝态（点亮/完成）可用轻量彩纸，克制不喧闹。
配色（状态语义色，全产品统一，星图与进度条同色系）：
  - 已掌握 mastered   = 绿      #00A63E（浅底 #F6FEF9；星图中带光晕）
  - 练习中 learning   = 主蓝    #2D8CFF（进行中徽标/进度，半亮）
  - 薄弱   weak       = 警示红  #FF6252（浅底 #FFEDEB）
  - 待复习 review_due = 中性蓝灰 #8E99B0（随时间变暗）
  - 未学   new        = 中性灰  #CCCCCC（暗星轮廓 / 空心星）
品牌主色 primary = 明黄 #FFE562（选中态/底部导航/星标 ★；文字压浅底用更深金 #FDC700）。
  · 主蓝 #2D8CFF = 次级强调 / 链接 / 可点文字；黄负责“品牌与选中”，蓝负责“链接与进行中”。
中性色阶：正文 #333 / 次要 #666 / 三级 #999 / 占位·禁用 #CCC。
背景 #F6F6F6；面板/浅底卡 #F3F4F6；卡片 #FFF；描边/分隔线 #EBEBEB。
星图暗色皮肤：深空底 #1B1B1B/#1E1E1E，星为暖白/星光白发光体。
圆角：按钮/输入 10；卡片 12；大卡/胶囊/分段控件 20。阴影极柔、低透明度。
字体：拉丁与数字 Inter；中文汉仪旗黑或系统中文无衬线回退；大字数据用 SemiBold/Bold。
单位规则：进度一律以「知识点 / 个」为单位，禁止出现 KP、题数、张数。
onboarding 通用骨架：顶部左上角返回箭头 ←；页面右侧一条竖向圆点进度条（共 12 屏，高亮当前）；
  每屏一个大标题（黑）+ 一行主色副标题（蓝/紫强调）；底部一个通栏主 CTA 胶囊按钮。
布局：平板优先，提供 landscape 与 portrait 两套。
负向清单：禁止在页头黄金位喊品牌名「云记」；禁止「未完成/欠账/0%」口径讲暗区（用「待点亮的星域」正向叙事）；禁止英文装饰水印。
```

## Prompt A1 — 你在备考什么？（exam_type 收集）

```
生成 onboarding 第 1 屏「你在备考什么？」。
大标题「你在备考什么？」+ 主色副标题「选一个，帮你定制专属学习空间」。
主体：2 列大按钮网格，每个按钮 = 图标 + 考试名，圆角 12、点击态用品牌黄 #FFE562 描边/浅底：
  法考 / 考研 / CPA / 教师资格 / 医学·执医 / 四六级 / 期末考试 / 其他。
底部主 CTA「继续 →」（未选禁用置灰 #CCC，选中后激活）。
作用备注（不显示给用户）：所选决定后续体验加载哪份示例样例包；产出字段 exam_type。
不要收集除“考什么”以外的信息，本屏只做一件事。
```

## Prompt A2 — 科目 + 考试时间（subject / exam_date 收集）

```
生成 onboarding 第 2 屏「你的考试信息」。
大标题「快到了吗？」+ 主色副标题「告诉我们科目和时间，自动排好每天学什么」。
两个输入区：
  ① 科目选择：一行可横滑的科目胶囊（随上一屏考试联动，示例：法考 → 刑法/民法/行政法/理论法…；默认选中「刑法」）。可多选，选中态品牌黄。
  ② 考试时间：一个日期选择器（大号、居中），下方小字实时反推「距考试还有 72 天」。
底部主 CTA「继续 →」。
字段映射（不显示）：科目=学习计划名称默认值 subject；考试时间=V2.0 Deadline exam_date。
不要在本屏暴露“每日学习时长/容量调节杆”——那些留到用户进入产品后。
```

## Prompt B2 — 秒变结构化笔记（价值点 1）

```
生成 onboarding 第 5 屏「你的 AI 笔记」。
顶部一行文件条：PDF 图标 +「刑法分论·贿赂渎职.pdf · 42 页 · AI 笔记」+ 右侧绿色「✓ Done」徽标。

  - 一张三列表格（如 情形 / 认定 / 依据）。

不吹 AI 技术，重点让用户感到“我那堆资料被整理干净了”。可保留“教材原图”徽标示意（资产抽取）。
```

## Prompt B3 — 点亮你的知识星图（价值点 2，大动图高潮）★

```
生成 onboarding 第 6 屏「点亮你的知识星图」（本流程视觉高潮，务必做成动图/动效）。
大标题「你的知识，连成一张星图」+ 主色副标题「学会一个，点亮一颗」。
严格复用主 prompts 文档 Prompt 3【星图视图 A】的全部规格，不要重画一套：
  - 深空底 #1B1B1B；星为暖白/星光白发光体；2 色制（未学暗灰 vs 已开始更亮，靠亮度大小深浅区分，不用糖果色）。
  - 必加背景星尘层 300~600 颗极暗小星填满暗空。
  - 相关星成紧致密簇 + 簇间大片暗空（按数据 x,y 画点、按 deg 定大小，不按章节分块、不均匀平铺）。
  - 章节名极淡大字水印作锚点（如「刑法分论·贿赂渎职」），避开最密星团；禁止任何英文水印。
动效脚本（onboarding 专属高潮）：
  - 进入：fly-to 到一个密簇并缓动放大。
  - 逐颗点亮：一批已掌握星依次由暗到亮 + 光晕扩散脉冲；同时向 top-3 邻居 draw-on 生长连线。
  - 顶部一行正向统计「本周新点亮 8 颗 · 54% 已亮」（探索叙事，不用欠账口径）。
底部：一句轻提示「还能切换成思维导图看结构」（仅文字带过，不展开三视图交互）+ 主 CTA「太酷了，继续 →」。
数据源：法考直接复用主 prompts 文档「星图假数据」的刑法 JSON；其余科目用对应示例包 starmap_json（同字段结构）。
```

## 使用建议

1. 生成顺序：按 A1→A2→A3→B1…B7→C1→C2 逐屏产出，保证同一份示例内容（法考·刑法）从头串到尾。
2. B3 星图是高潮屏，直接引用主 prompts 文档 Prompt 3 的完整星图规格与刑法 JSON，不要另写星图逻辑；其余科目替换为对应示例包的同结构 JSON。
3. B4/B5 的闪卡与题型必须复用主 prompts 文档 Prompt 3b/Prompt 4 的组件与反馈规则，禁止重新发明样式。
4. B6/B7 的报告分别以主 prompts 文档 Prompt 2 / Prompt 5 为母版收敛，不自行编造预测与组卷逻辑。
5. 每屏保持“一屏一件事 + 一个主 CTA + 右侧圆点进度”，节奏对齐竞品 Thetawave 的体验流手感。
6. 全程遵守负向清单：不在黄金位喊品牌、不用欠账口径讲暗区、不伪造练习掌握分、不加英文装饰水印。
