为「云记学习模式」生成 Today 页（默认页、最高频）。回答三个问题：今天学/复习什么、今天到哪了、怎么开始。整页自上而下单列（即使横屏也保持单列居中，最大宽度 720，两侧留白），Hero 随页滚动、不固定。

【⓪ 页头（Hero 之上，轻量）】
  - 大标题 H1 = 当前**学习空间名**「刑法」。不要写品牌名「云记」（用户已在 App 内）。H1 右侧带一个小下拉箭头 ⌄。
    · ‼【下拉要真能点、真弹面板（不是只画个箭头）】点击 H1 文字**或**箭头 ⌄ → 弹出一个下拉面板，列出用户的全部**学习空间**（如「法考·刑法」「Biology 101」「World History」等，当前项打勾高亮），选中某项即切换，整页 Today / Overview / 星图数据跟随新空间刷新。这是跨学习空间切换，**不是**法考内部的科目切换（本产品不设"科目"中间层）。请把这个下拉交互画出来（含展开态示意），别只放一个不可点的静态箭头。
  - 副标题位 = 「考考你」微测验模块（取代原静态引导语「稳住节奏…」）：一句从已掌握知识点抽出的提问，如「还记得吗：斡旋受贿罪的行为主体是谁？」，右侧一个小图标暗示可点。视觉是一行轻互动，不是一张大卡。产出两态示意：默认抽题态 / 运营配置态（整块换成运营指定文案，可带活动链接）。
    · ‼【整行可点、要有明确落点（AI 常漏做成不可点）】整行是一个热区，点击 → 打开**该知识点的全屏预览闪卡（即 Prompt 1b）**，与今日任务里点知识点名是同一个落点：正面看提问、翻面看概念、可从该点拉起练习。不要做成不可点的纯文字。运营配置态则跳运营指定链接。
    · 优先级：运营配置文案 > 默认抽题 > 价值引导语兜底。零数据（无历史已掌握且无运营配置）时回落到「稳住节奏，离上岸又近一天」。
    · 不要写成功能说明（禁止「智能分析：今天学什么/今天到哪了/怎么开始」这类给 AI 看的话）。
  - 不要单独的「TODAY」徽标——底部导航已高亮 Today，勿重复强调。
  - ‼【页头负向清单（与 Overview 一致，AI 常自行脑补冗余头部，逐条禁止）】页头只有 H1 科目名（带切换下拉 ⌄）+ 「考考你」副标题位，别的一律不加。明确禁止：
    · 禁止品牌名「云记」出现在页头黄金位（用户已在 App 内，顶部已有导航）。
    · 禁止端类型 / 环境标签，如「学习平板端」「学习模式」这类零信息占位词。
    · 禁止营销 slogan / 功能吹嘘副标语，如「大数据动态融合模型 · 助力轻松通过法考」——副标题位只放「考考你」微测验或其兜底引导语，不放这类静态吹嘘。
    · 禁止单开一个占宽的科目胶囊（如「科目：刑法总论 + 刑法分论」）。科目切换只用 H1 右侧的小下拉箭头 ⌄，不单独成块、不占一行。

【① Hero 概览卡（今日概览，置顶）】
一张大卡，横向分**两个区**：左「状态区」+ 右「行动区」。心理路径 = 我现在到哪了（状态）→ 点这里开始（行动）。
  - ‼【结构：两区，不是三区；禁止再造重复的"今日目标"进度块】Hero 里进度只表达**一次**（左区那个环形 50%）。**严禁**在环形之外再画一条"今日目标 12 个知识点 · 6/12 已完成"之类的第二进度条——那和环形是同一个 6/12，重复且制造"视觉一直跳"。左右两区职责：
    · **左·状态区**：环形 50%（主角）+ 情绪/动机文案 + 三个依附小标签，全部是"我现在学得怎么样"这一件事，融合成一个信息组，**不要拆成多张 Card 套 Card**（学习节奏、距考试是小标签，不是独立卡片）。
    · **右·行动区**：以「开始今日学习」CTA 为绝对主角 + 其下「约 45min」预计时长。**行动区只放这两样**，见下方禁止项。
  - ‼【视觉层级：环形 + CTA 是唯二主角，其余全部退一级】环形描边够粗、50% 数字够大够醒目；CTA 做成高对比实心大按钮（主色/深色，够大够显眼），右区其余留白衬托它，让 CTA 成为落点而非孤悬的小按钮。「今天还差一点！」是**次级情绪文案**，可有存在感但**不得盖过环形与 CTA**（现在的毛病就是它成了全卡最大元素、喧宾夺主）。
  - 大字「今天还差一点！」+ 副行**收尾动机文案**：把原来空洞的「已处理 6/12 个知识点」升级为有临门一脚感的说法，如「再 6 个，今天就能收尾」（Duolingo 式完成激励，用剩余量驱动继续）。这块文案可点，进入 Prompt 1a「计划概览页」。
  - 主按钮「开始今日学习」（图标交给生成器，不要手敲多个 ▶），按钮下小字「约 45 min」。
  - ‼【行动区禁止项（AI 常往这里灌信息填空）】右·行动区**只有 CTA + 「约 45min」**，不要再加：下一个任务 / 模块名（如"下一个：受贿罪专题"）、剩余任务时长明细、第二进度条、任何达成率。想挑模块走下面「今日任务」列表；Hero 这个入口的定位是"别让我选、带我走"。右侧空一点没关系——解法是让 CTA 长大 + 容器收窄，不是灌内容把广告位填满。
  - 文案热区与主按钮热区分离：点击「今天还差一点！」只查看计划概览，不开始练习。
  - 只有这一个主 CTA：不要并列第二个同级大按钮（如「云记 AI 学习」）。AI 富对话只通过入口闪卡深度学习、当日连续错3次提示、当日累计错20次强干预触发，不是 Today 上的独立入口；练习模式选择也挂在这个唯一入口内。
  - 卡片底部一行三个小标签：「🔥 7 天连续」「⏱ 今日已学 25min」「⏳ 距考试 72 天」。这一行**横向铺满卡片底部**（三标签均分 / 两端对齐），不要三个胶囊孤零零挤在左下角、右侧留大片空。
  ‼ 约束：Hero 只放这 5 个数据（环形完成度 + CTA/预计时长 + 上述三小标），**逐条禁止**往里加：达成率 / 目标通过率（属 Overview 预测，AI 反复往 Hero 塞）、考试日期（如"2026.09.10 考试"）、累计天数、资料状态、以及任何第二条进度条。
  「今日已学 25min」= 当日累计学习时长，与「约 45min 预计时长」形成「已学 vs 预计」对照；它不是设置里的「学习时间（每天开始时刻）」。
  距考试天数按剩余占比分档变色（仅这一个小标变色，其余不跟着变，避免整卡泛红）：
    · 剩余占比 = 剩余天数 ÷ 计划总天数。> 30% = 中性灰；7%~30% = 暖橙 #E17100；≤ 7% = 警示红 #FF6252（可轻微加粗，仍是小标不放大）。
    · 用百分比而非绝对天数，保证 30 天 / 300 天计划都适用。示例 72 天属常规灰；生成时可另出一张「≤7% 红色紧迫」态示意。
  环内文字：用中文（如「今日」）或留空，不要写英文「DONE」。
  冷启动态（首日）：主文案改为「开始你的第一天 →」，不显示 0% 环形、不显示「0 天连续」、不显示「今日已学 0min」。冷启动是另一种页面状态，不是页面上的切换开关——不要画「正常进度 / 首日冷启动」之类的 toggle 控件。

【口径锁定（全页唯一进度来源，必须一致）】
  - 三处数字必须是同一组：Hero 环形 = 50%；Hero 副行 = 已处理 6 / 12；今日任务标题右侧 = 已处理 6 / 12。
  - Today 使用「已处理」（包含完成学习/复习与用户跳过）；Overview 才使用「已验证掌握」，两种口径不要混用。
  - 进度单位一律「知识点 / 个」，禁止 KP、题数、张数。

【② 今日任务（单容器 · 三级折叠 —— 这是预览/管理面，不是发射器）】
标题行：左「今日任务」，右「已处理 6 / 12 知识点」。
整块是**一张卡容器**，内部三级折叠：类型（新学 / 复习）→ 模块 → 知识点。不要拆成「待学习」「待复习」两个独立卡容器——那样浪费卡间 margin、分区标题也冗余。层级只靠缩进 + 细分隔线表达。
默认展开状态：进页时 L1 两个类型头都展开、露出各自模块行；L2 模块默认收起（不露知识点）；L3 知识点按需展开。
  · L1 类型头：可折叠，默认展开。显示「类型名 · X 块 · Y 知识点」，如「▾ 新学 · 3 块 8 知识点」。类型只承担「学 vs 复习」这一个维度，不与进度状态混用。两个类型层之间用一条细分隔线，不是两张卡的留白。
  · L2 模块行收起态显示：模块名 + 「X/Y 知识点」 + 预计时长 + 状态标签（未开始/练习中/已完成）+ 右侧一个显式次级按钮「▶ 开始学习 / 继续学习 / 开始复习」。进度状态不要再堆额外彩色标签，交给状态文字 + 按钮文案承载（未开始→开始学习、练习中→继续学习、复习类型→开始复习），一行最多 1 个状态信号。
重要（平板无 hover）：开始练习的承诺动作只靠显式按钮，不靠「整行可点」。行主体/箭头点击=展开预览（高频，为主）；右侧「▶ 开始」按钮=用算法练这个模块（次级，弱于展开）；L1 类型头点击=折叠/展开该类型下全部模块行。
模块行左侧有独立的展开箭头热区 ▸。点行主体或箭头都只是内联展开看明细，不进练习。
L2 展开态在行内列出该模块的知识点，每行：复选框 ☐ + 知识点名 + 状态图标（✓已掌握 / ◐练习中 / ○未开始）+ 右侧收藏星标 ☆/★。注意用缩进 + 字号把 L3 知识点与 L2 模块拉开层级，别让用户分不清展开的是模块还是知识点。
  - 点知识点名 → 打开全屏预览闪卡（见 Prompt 1b），仅预览/筛选/快速复习，不直接拉起整模块练习。
  - 点右侧 ☆ → 收藏该知识点（变 ★）；收藏是纯书签（标记「重要/待巩固」），在 Overview 汇成「我的收藏」列表，不改出题算法与权重。
  - 勾选若干知识点 → 行内底部出现一行「选中 N 项　[我已经会了，跳过学习] [批量重置进度]」：
    · 我已经会了，跳过学习 = 一键移出当前计划，记为用户自评待验证；不伪造练习掌握分。仍可在模考 / 低频抽检出现，答错后恢复到计划。无需二次确认。
    · 批量重置进度 = 把选中项掌握度归 0、退回待学（用于想从头再学）；与「标记已掌握」相反、无自动兜底，故点击弹一次轻确认「重置 N 个知识点的学习进度？」。

区底部一个文字按钮「查看全部 →」（点击跳 Overview 的全屏星图并落在「今日待学/待复习」筛选）。

【新手引导：悬浮气泡 bubble（递进 + 用完即撤，不要占行的小字提示）】
不要在页面底部放常驻的「帮助中心 / 极简三问」卡，也不要用占据一整行布局的常驻小字提示条——前者永久占版面，后者新手期会把列表撑开。改用悬浮气泡 bubble：一个带图标（💡）+ 关闭 ✕ 的浮层，锚在对应功能旁、带一条指向该热区的小尾巴，浮在界面之上而不占列表行高与 margin。产出两种页面状态示意（新手期「有气泡」态 与 老用户「无气泡」干净态）。
通用机制：气泡是覆盖层、不撑开布局；一次只浮一个（递进，前一条对应操作完成后才出现下一条）；每个气泡绑「对应操作是否已做过一次」标记，做过一次即永久撤下（按次数不按天，跨会话持久化）；气泡必须用尾巴明确指向讲解的热区，且不遮挡该热区本身。用状态示意表达，不要画成 toggle 控件。
  A. Hero 气泡（首次进入，仅 1 条）：气泡指向「开始今日学习」按钮，文案「点这里开始今天的学习」，点过即撤。首次不提示「切换练习模式」（进阶项，留到练习页/二次回访）。
  B. 类型层说明气泡（指向 L1 类型头，新手期递进）：
     · 指向「新学」类型头：「今天新学的知识点，已按模块分好。」
     · 指向「复习」类型头：「学过、到点该回顾的，趁没忘过一遍。」
     · 各自随对应类型头被展开/折叠过一次即撤。
  C. 模块行操作气泡（只做最易混 2 条，递进出现，一次只浮一个）：
     · 气泡①（点行=看明细）：指向第一条模块行，文案「点开看这个模块今天学哪些 ▸」。
     · 气泡②（▶开始=单模块练）：气泡①用过后才出现，文案「点击『开始』直接练习该模块，已跳过的会自动略过」。
  D. 展开态内气泡（用户展开模块后就地给，不占首屏）：
     · 首次见复选框时，气泡指向批量操作栏：「勾选知识点可批量操作——会了就跳过学习，或重置进度从头再学」。
     · 首次见星标时，气泡指向星标：「点 ☆ 收藏重点知识点，稍后在 Overview 集中回看」。
  不进首屏递进链：「点知识点名看闪卡」属进阶，不教。
  Hero 的环形与「开始今日学习」CTA 本身不加气泡（除 A 那一条引导点击外，进度环足够自明）。

交互要点（模块行上三个独立显式热区 + 类型头，平板均为可点对象，不靠 hover）：
  - L1 类型头 ▾/▸ = 折叠/展开该类型下全部模块行；
  - 行主体/展开箭头 ▸ = 内联展开预览（为主）；
  - 右侧「▶ 开始」按钮 = 用算法练该模块（次级）；
  - 知识点名 = 打开全屏预览闪卡。
另：练习模式选择（默认 / 单题型）属于练习流，挂在 Hero「开始今日学习」入口，不出现在今日任务列表与预览里。
不要暴露「刷多少张闪卡/多少道题」——只承诺学哪些模块。
不要单独的「今日进度」区块——Hero 的环形完成度是全页唯一进度来源，页尾不再重复。
